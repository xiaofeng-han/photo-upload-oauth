# photo-upload-oauth

Static homepage, privacy policy, terms of service, and optional 120x120 logo for **photo-upload**, a personal tool that backs up one person's self-hosted Immich photo library to Google Photos. Designed to be served by GitHub Pages and referenced from the Google Auth Platform **Branding** page.

- Home: `https://xiaofeng-han.github.io/photo-upload-oauth/`
- Privacy: `https://xiaofeng-han.github.io/photo-upload-oauth/privacy.html`
- Terms: `https://xiaofeng-han.github.io/photo-upload-oauth/terms.html`
- Authorized domain: `xiaofeng-han.github.io`

This directory contains static branding assets only (no secrets or runtime code).
